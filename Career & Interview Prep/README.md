## 📄 Resume rules (1 page, ATS-friendly)
- Template: [Jake's Resume (Overleaf)](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) or any single-column template.
- Order: Skills → Experience → Projects (TicketVerse, CareerPilot/DocuMind) → Certifications → Education.
- Every bullet = **impact**: *"Did X, measured by Y, by doing Z."* Numbers beat adjectives.
- **Mine your current job** (maintenance work counts!):
  - "Optimised a reporting stored procedure: 40 s → 6 s by adding a covering index and removing a cursor."
  - "Fixed N production defects in the order module; reduced repeat incidents by X% via tests."
  - "Migrated config to Spring profiles, cutting deployment errors…"
  Ask yourself: What did I speed up, fix, automate, or own? Who benefited? By how much?
- Project bullets you'll earn (examples): *"Built TicketVerse, a Spring Boot 4 microservices platform (Kafka saga, Redis seat holds, OAuth2) handling N req/s with zero double bookings under a 100-thread test; deployed to Azure (AKS/Container Apps, PostgreSQL, Key Vault) with GitHub Actions."*

## 🔗 LinkedIn & Naukri
- **Headline formula:** `Java Backend Engineer | Spring Boot · Microservices · Kafka | Azure (AZ-104) | Building with LLMs (RAG, Agents)`
- **About:** 3 lines on what you build + 3 bullets of proof (projects, certs) + what you're looking for.
- **Featured:** TicketVerse repo, demo video, a design write-up.
- Post every 2–3 weeks about something you built (short, with a diagram). Engage with posts from target companies.
- **Naukri:** keep key skills aligned with target JDs; refresh the profile weekly once you start applying.

## 🗣️ Behavioural prep
- Use **STAR** (Situation, Task, Action, Result) — 60–90 seconds per answer; end with a measurable result and a learning.
- Keep 8–10 stories that you can reuse across questions → [STAR_STORY_BANK.md](STAR_STORY_BANK.md).
- Guide: [Tech Interview Handbook — behavioural](https://www.techinterviewhandbook.org/behavioral-interview/).

## 💰 Negotiation basics (W24)
- Research ranges for your target role/city: [AmbitionBox](https://www.ambitionbox.com/), [Glassdoor](https://www.glassdoor.co.in/), [levels.fyi](https://www.levels.fyi/).
- Try not to quote a number first; if forced, give a researched range anchored at the upper side. Compare **total** compensation.
- Competing offers are your strongest lever — time your applications so offers land close together.
- Get the final offer in writing before resigning.
