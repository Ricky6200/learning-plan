# 🎯 Java Backend Interview Question Bank (239 questions)

High-frequency questions from Indian product/service-company Java backend interviews (SDE-1 → SDE-2), mapped to the week that teaches them.
**⭐ = asked very often — master these first.** `(W5)` = week that covers it.

**How to use**
- Answer **aloud in 60–90 seconds** using: **Define → How it works → Example from *your* code → Pitfall/trade-off**.
- Mark each question in your notes: ✅ confident · 🟡 shaky · ❌ can't answer. Re-test 🟡/❌ after 1, 7 and 21 days.
- Sunday tests draw from the current week's section plus one older ⭐ question; W26 revises the whole bank daily.
