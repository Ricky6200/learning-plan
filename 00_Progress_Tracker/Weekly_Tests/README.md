# 🗂️ Weekly Tests

One file per Sunday test, created by the AI mentor following [WEEKLY_TEST_PROTOCOL.md](../WEEKLY_TEST_PROTOCOL.md).

- Naming: `Week-01-Test.md`, `Week-02-Test.md`, … (`Week-04-BOSS-Test.md` in boss weeks, `Week-09-Rematch.md` for rematches)
- Each file contains: questions · your answers (code kept verbatim) · model answers · marks with reasons · weak topics · remediation · XP.
- Scores roll up into [TEST_SCOREBOARD.md](../TEST_SCOREBOARD.md); weak topics into [WEAKNESS_TRACKER.md](../WEAKNESS_TRACKER.md).

> Tip: re-read the last 2 test files every Sunday morning before the new test — it's the fastest way to fix repeated mistakes.
